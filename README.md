# منصة أكاديمية دقيش التعليمية برج بونعامة

منصة تعليمية متكاملة تجمع بين التعليم الرقمي، المتابعة المستمرة، والاختبارات الذكية لطلبة التعليم المتوسط والثانوي.

## 🚀 التقنيات المستخدمة
- **Next.js**: إطار عمل React للتطبيقات السريعة والمحسنة (App Router)
- **Tailwind CSS**: تصميم الواجهات بطريقة عصرية وسريعة
- **Prisma & Supabase**: إدارة قواعد البيانات
- **Lucide React**: أيقونات عصرية

## 🛠️ كيفية التشغيل محلياً

1. تثبيت الحزم:
```bash
npm install
```

2. إعداد متغيرات البيئة:
قم بإنشاء ملف `.env` وانسخ المتغيرات اللازمة للاتصال بقاعدة البيانات.

3. تشغيل خادم التطوير:
```bash
npm run dev
```

المنصة ستكون متاحة على: [http://localhost:3000](http://localhost:3000)
